# MMR 계산 산식 문서

커스텀 5v5 매치 로그로부터 플레이어별 종합 MMR과 라인별 MMR을 산출하는 산식의 전체 로직과 계산식을 정리한 문서입니다.

- **입력**: 경기별·참가자별 매치 로그 (`mmr_participant_metric`), 계정 매핑 (`riot_account`), 길드 멤버/부계정 매핑 (`guild_member`)
- **출력**: 플레이어별 종합 MMR, 라인별(top/jungle/middle/bottom/utility) MMR·승률·게임수, 정식/배치중 구분
- **규모**: 2,443경기 × 10명 = 24,430행, 통합 후 201명

---

## 1. 전체 로직 흐름

산식은 한 문장으로 "**시간순으로 한 경기씩 처리하는 팀 단위 Elo에, 개인 퍼포먼스·라인전·포지션·승부격차 보정을 K값에 곱한 것**"입니다. 처리 순서는 다음과 같습니다.

| 단계 | 이름 | 하는 일 |
|------|------|---------|
| 0 | 데이터 정리 · 계정 통합 | 유효 경기 필터링, 부계정 puuid를 메인계정으로 치환 |
| 1 | 퍼포먼스 점수 산출 | 포지션별 지표를 robust z로 표준화 후 가중 합산 |
| 1.5 | 승부격차(blowout) 강도 | 경기별 골드차·게임시간으로 압승/접전 강도 계산 |
| 2 | 시간순 Elo 갱신 | 경기마다 기대승률 → K값 보정 → 점수 갱신 |
| 3 | 결과 집계 | 종합·라인별 MMR/승률/게임수 정리 |
| 4 | 랭킹 컷 적용 | 20판 이상 정식 / 미만 배치중 분리 |

각 단계의 상세 계산식은 아래에서 다룹니다.

## 2. 하이퍼파라미터

산식에 쓰이는 상수는 다음과 같습니다.

| 기호 | 코드명 | 값 | 의미 |

## 3. 단계별 상세 계산식

### 3-0. 데이터 정리 · 계정 통합

먼저 유효한 경기만 남깁니다.

```
df = df[ is_mmr_eligible == True  AND  is_deleted == False ]
```

다음으로 한 사람이 여러 계정으로 플레이한 경우를 한 명으로 합칩니다. `guild_member`에서 `is_main = False`인 부계정과 그 메인계정의 매핑을 가져와, player_code를 puuid로 변환한 뒤 **부계정 puuid를 메인 puuid로 치환**합니다.

```
puuid  ←  merge_map.get(puuid, puuid)
```

이 치환을 Elo 계산 **이전에** 수행하므로, 부계정에서 쌓은 경기·점수가 모두 같은 계정으로 누적됩니다. (실제 데이터: 부계정 8개, 경기행 95개가 통합됨)

### 3-1. 퍼포먼스 점수 (perf_z)

같은 승패라도 잘한 사람과 묻어간 사람을 구분하기 위한 개인 기여 점수입니다. 핵심은 **포지션별 모집단 내 상대평가**입니다. (서포터의 낮은 CS가 불이익이 되지 않도록)

**(1) robust z-score** — 각 지표를 같은 포지션 사람들 안에서 표준화합니다. 평균·표준편차 대신 중앙값·IQR을 써서 이상치(가끔 터지는 고KDA 등)에 강건합니다.

```
            x − median(x)
robust_z =  ─────────────── ,  [−3, +3] 으로 clip
            Q₃(x) − Q₁(x)
```

여기서 Q₁, Q₃는 1사분위·3사분위 값이고, x는 해당 포지션 모집단의 지표값입니다. IQR이 0이면 표준편차로 대체합니다.

**(2) 가중 합산** — 각 포지션마다 "공통 + 라인전 + 포지션특화" 지표의 robust_z에 가중치를 곱해 더합니다.

```
raw_perf(player) =  Σ  w_feat · robust_z(feat)
                   feat ∈ (공통 ∪ 라인전 ∪ 포지션특화)
```

사용 지표와 가중치는 다음과 같습니다.

**공통 지표 (모든 포지션)**

| 지표 | 가중치 | 설명 |
|------|--------|------|
| `kda` | 0.8 | (킬+어시)/데스 |
| `dpm` | 0.5 | 분당 챔피언 피해 |
| `gold_per_min` | 0.4 | 분당 골드 |

**초반 라인전 지표 (모든 포지션, 팀운 무관 개인기량이라 비중 큼)**

| 지표 | 가중치 | 설명 |
|------|--------|------|
| `lane_gold_diff` | 0.8 | 라인 상대와의 골드차 (가장 순수한 라인전 우위) |
| `takedowns_before_15min` | 0.7 | 15분 이전 킬관여 수 |
| `turret_plates_destroyed` | 0.4 | 포탑 방패 파괴 (초반 압박) |

**포지션 특화 지표 (역할별 핵심 기여)**

| 포지션 | 지표 (가중치) |
|--------|---------------|
| TOP | `damage_to_champions`(0.4), `damage_self_mitigated`(0.3) |
| JUNGLE | `damage_to_objectives`(0.7), `dragon_kills`(0.4), `vision_score`(0.3) |
| MIDDLE | `damage_to_champions`(0.6), `cs_per_min`(0.3) |
| BOTTOM | `damage_to_champions`(0.7), `cs_per_min`(0.4) |
| UTILITY | `vision_score`(0.7), `heal_on_teammates`(0.3), `shield_on_teammates`(0.3), `cc_time`(0.3) |

**(3) 재표준화** — 합산값을 전체 모집단 기준으로 다시 표준화(z)하고 [−2.5, 2.5]로 clip합니다.

```
            raw_perf − mean(raw_perf)
perf_z  =  ───────────────────────────  ,  [−2.5, +2.5] 으로 clip
              std(raw_perf)
```

### 3-2. 승부격차 강도 (blowout)

경기가 압승이었는지 접전이었는지를 −1~+1로 나타내는 경기 단위 값입니다. 두 신호를 씁니다.

- **주 신호**: 팀 골드차 절대값 `|Σgold(blue) − Σgold(red)|` — 클수록 압승
- **보조 신호**: 게임 시간 `game_duration` — 짧을수록 압승

두 신호를 각각 robust 표준화한 뒤 결합합니다. (게임시간은 부호를 빼서 "짧을수록 +"가 되게 함)

```
blow_raw  =  rz(gold_diff)  −  rz(duration)
```

이를 다시 표준화한 뒤 tanh로 −1~+1 범위에 부드럽게 누릅니다.

```
              blow_raw − mean(blow_raw)
blow  =  tanh( ─────────────────────────── ) ,  내부값은 [−3,3] clip
                  std(blow_raw)
```

이 `blow` 값은 경기마다 하나씩 정해지며, 그 경기에 참여한 10명 전원에게 동일하게 적용됩니다.

> 작동 예시: 13분 만에 골드차 1.3만으로 끝난 압승 → blow ≈ +0.91, 49분 풀타임 골드차 100 접전 → blow ≈ −0.95

### 3-3. 시간순 Elo 갱신 (핵심)

경기를 `played_date` 순서로 한 판씩 처리합니다. 모든 플레이어는 1500에서 시작합니다.

**(1) 기대승률** — 각 팀 5명의 현재 종합 MMR을 평균 내어 표준 Elo 로지스틱에 넣습니다.

```
                         1
E_blue  =  ──────────────────────────────
            1 + 10 ^ ((R_red − R_blue) / 400)

E_red   =  1 − E_blue
```

여기서 R_blue, R_red는 각 팀 5명의 평균 MMR입니다. 강팀(평균 높음)을 이기면 E가 낮았으므로 더 큰 보상을 받습니다.

**(2) 실제 결과** — 승리 팀은 s = 1, 패배 팀은 s = 0. (같은 팀 5명은 동일 결과 공유)

**(3) K-factor 보정** — 기본 K(32)에 세 가지 보정을 곱합니다.

```
K  =  K_BASE
      × (배치 보정)
      × (퍼포먼스 보정)
      × (승부격차 보정)
```

각 보정은 다음과 같습니다.

*배치 보정* — 누적 10경기 미만이면 K를 1.5배:

```
배치 보정 = 1.5   (누적경기 < 10)
          = 1.0   (그 외)
```

*퍼포먼스 보정* — 이긴 경기에 잘했으면 K↑, 진 경기에 잘했으면 K↓ (손실 완화). tanh로 영향을 ±35%로 제한:

```
승리 시:  퍼포먼스 보정 = 1 + 0.35 · tanh(perf_z)
패배 시:  퍼포먼스 보정 = 1 − 0.35 · tanh(perf_z)
```

*승부격차 보정* — 압승(blow>0)이면 K↑(실력 신호 강하게), 접전(blow<0)이면 K↓(운 노이즈 완화). 영향 ±25%:

```
승부격차 보정 = 1 + 0.25 · blow
```

마지막으로 K의 하한을 4로 둡니다 (`K = max(K, 4)`).

**(4) 점수 갱신** — 표준 Elo 갱신식으로 각 플레이어의 MMR을 움직입니다.

```
Δ  =  K · (s − E)

R_new  =  R_old + Δ
```

이 Δ는 종합 MMR과 **그 경기에서 뛴 포지션의 라인 MMR에 동시에** 누적됩니다.

```
total_mmr[player]        +=  Δ
line_mmr[player, 포지션]  +=  Δ
```

### 3-4. 결과 집계

플레이어별로 다음을 계산합니다.

- **종합 MMR**: 위에서 누적된 total_mmr
- **종합 승률**: `100 × 승리수 / 전체경기수`
- **라인별 MMR/승률/게임수**: 각 포지션에서 누적된 line_mmr과 해당 포지션 경기 기준 승률
- **주 포지션**: 게임수가 가장 많은 포지션

### 3-5. 랭킹 컷 적용

표본이 적으면 MMR이 시작값(1500) 근처에서 거의 안 움직여 순위가 무의미해집니다. 이를 걸러내기 위해 20판 컷을 둡니다.

```
정식 랭킹  :  total_games ≥ 20   → MMR 내림차순으로 1위부터 순위 부여
배치중      :  total_games < 20   → 순위 미부여, 별도 표시
```

(실제 데이터: 정식 139명, 배치중 62명)

## 4. 설계 의도 요약

이 산식이 단순 승패 기록과 다른 점은 "**운과 실력을 분리**"하려 한다는 것입니다.

- **팀 평균 Elo**: 혼자가 아니라 팀으로 이긴 것이므로, 상대 팀 실력을 반영해 강팀을 이긴 가치를 더 쳐줍니다.
- **퍼포먼스 보정**: 같은 승패라도 캐리한 사람과 묻어간 사람을 구분하고, 캐리한 패배의 손실을 줄여줍니다.
- **라인전 지표**: 라인 골드차·초반 킬관여는 팀운과 무관한 개인 기량이라, "팀 잘 만나 이긴 사람"과 "본인이 라인전을 압도한 사람"을 구분합니다.
- **포지션별 가중치**: 정글의 오브젝트, 서포터의 시야처럼 역할마다 다른 핵심 기여를 정확히 평가합니다.
- **승부격차 보정**: 압승은 실력 신호가 강하니 점수를 크게 움직이고, 운에 좌우되는 신승/석패는 덜 움직여 노이즈를 줄입니다.

검증 결과, 라인 골드차와 종합 MMR의 상관계수가 약 0.78로 나타나 라인전 강자가 실제로 높게 평가됨이 확인되었습니다.

## 5. 조정 가능한 파라미터

산식을 튜닝하려면 다음 값을 조정합니다.

| 목적 | 파라미터 | 방향 |
|------|----------|------|
| 점수 변동폭 키우기/줄이기 | `K_BASE` (기본 32) | ↑ 변동 큼 / ↓ 안정적 |
| 퍼포먼스 비중 | `PERF_GAIN` (기본 0.35) | ↑ 개인기량 영향 큼 |
| 승부격차 비중 | `BLOWOUT_GAIN` (기본 0.25) | ↑ 압승 가치 큼 |
| 라인전 비중 | `PERF_LANE` 가중치 | ↑ 라인전 영향 큼 |
| 역할 평가 | `PERF_ROLE` 지표·가중치 | 포지션별 지표 추가/교체 |
| 랭킹 진입 기준 | `CUT` (기본 20) | ↑ 신뢰도 빡셈 |

### 추후 적용 가능한 보정 (미적용)

- **라인별 베이지안 수축**: 표본 적은 라인 MMR을 전체 평균으로 끌어당겨 과대평가 방지
- **최근 경기 시간 가중**: 오래된 경기 영향을 줄여 "현재 실력" 반영 (데이터가 5개월치 누적이므로 효과 있음)
