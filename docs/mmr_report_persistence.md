# TRC-321 MMR 플레이 리포트 DB 연동 설계

MMR 리포트는 기존 경기 결과를 이력으로 사용하고, 기존 유저 요약에 포지션별 최신
리포트 결과를 JSON으로 저장한다. 별도의 이력·포지션 요약 테이블은 생성하지 않는다.

## 실행

```bash
python scripts/run_mmr_report_once.py
```

이 명령은 필요한 컬럼 마이그레이션을 적용한 뒤 기존 전체 계산 배치를 실행한다.
최종 유저 요약에는 현재 활성 길드원만 저장하며, 스타일 비교 모집단 계산은 전체 계산
대상을 유지한다. 재실행 시 계산 대상 경기 결과와 길드별 최신 유저 요약을 같은
트랜잭션에서 교체한다.

경기별 기간 비교 기준은 서비스 정책 확정 후 기존 경기 결과의 경기 일시를 이용해
조회 계층에서 결정한다.

내부 분류 기준, 상세 쿼리 및 운영 정책은 보안상 사내 Confluence에서 관리한다.
