# MMR 산식 변경 이력

초기 설계부터 현재까지의 모든 변경점을 시간순으로 정리한 문서. 각 단계가 무엇을, 왜 바꿨는지와 그 효과를 기록한다.

---

## 현재 산식 한눈에 (최종 상태)

종합 MMR은 "**시간순 팀 Elo + 개인 퍼포먼스·라인전·포지션별·승부격차 보정**"으로 계산하고, 라인별 MMR에는 추가로 **베이지안 수축**을 적용한다.

**핵심 파라미터**

| 파라미터 | 값 | 의미 |
|----------|-----|------|
| `INIT_MMR` | 1300 | 시작 점수 |
| `K_BASE` | 32 | 기본 K-factor |
| `SCALE` | 400 | Elo 로지스틱 스케일 |
| `PERF_GAIN` | 0.35 | 퍼포먼스 K 조정폭 (±35%) |
| `BLOWOUT_GAIN` | 0.25 | 승부격차 K 조정폭 (±25%) |
| `PROV_GAMES` / `PROV_MULT` | 10 / 1.5 | 배치 기간 / 배치 K 배수 |
| `SHRINK_K` | 12 | 라인 MMR 수축 강도 (가상 경기수) |
| `CUT` | 20 | 정식 랭킹 최소 경기수 |
| 라인 노출 컷 | 5 | 라인 탭/통계 노출 최소 경기수 |
| 데이터 컷 | 10 | 10판 미만 완전 제외 |

## 변경 이력 (시간순)

### v0 — 초기 설계 (배치 Elo)

최초 구현. 다음을 갖춘 시간순 팀 Elo.

- 시작 1500, K=32, 시간순 5v5 팀 평균 Elo
- 기대승률: `E = 1 / (1 + 10^((R_상대−R_본인)/400))`
- 갱신: `Δ = K · (s − E)`
- **배치 보정**: 첫 10경기 K를 1.5배
- **퍼포먼스 보정**: 7개 공통 지표(KDA·DPM·골드·오브젝트딜·시야·라인골드차·CS)를 포지션별 robust z로 표준화 → K를 ±35% 조정. 이긴 게임 잘하면 +더, 진 게임 잘하면 −덜.
- **라인별 MMR**: 같은 Δ를 종합과 해당 포지션에 동시 누적

> 결과: 209명, MMR 분포 약 912~2627.

---

### v1 — 닉네임 매칭

riot_account의 `riot_name`이 CP1252로 깨져 저장된 것을 CP949로 복구. puuid를 키로 MMR 결과에 실제 닉네임 연결. (player_code↔puuid 1:1, 209명 전원 매칭 성공)

**변경점**: 표시용 닉네임 추가. 산식 자체는 불변.

---

### v2 — 부계정 통합

`guild_member`에서 `is_main=False`인 부계정 8개와 메인계정 매핑을 가져와, **부계정 puuid를 메인 puuid로 치환**. 치환을 Elo 계산 *이전에* 수행해 부계정 기록이 메인에 합산되게 함.

**변경점**: 0단계에 계정 통합 추가. 209명 → 201명. 부계정 보유자 8명의 표본·MMR 갱신.

---

### v3 — 최소 경기수 컷 + 배치중 분리

표본이 적으면 MMR이 시작값 근처에서 안 움직여 순위가 무의미한 문제. 진단 결과 하위 20%가 6판 이하, 중앙값은 106판으로 양극화.

- **20판 컷** 도입: 20판 이상 정식 랭킹, 미만은 "배치중"으로 분리 표시
- UI에 배치중 토글, 배지 추가

**변경점**: 5단계(랭킹 컷) 추가. 정식 139명 / 배치중 62명.

---

### v4 — 라인전 지표 + 포지션별 가중치 (퍼포먼스 보정 개편)

기존 퍼포먼스 보정은 모든 포지션이 같은 7개 지표·같은 가중치를 사용 → 역할 특성 무시. 두 가지로 개편.

**(A) 초반 라인전 지표 추가** (팀운 무관 개인기량이라 비중 큼)
- `lane_gold_diff`(0.8), `takedowns_before_15min`(0.7), `turret_plates_destroyed`(0.4)

**(B) 포지션 특화 지표 차등**

| 포지션 | 특화 지표 |
|--------|----------|
| TOP | damage_to_champions(0.4), damage_self_mitigated(0.3) |
| JUNGLE | damage_to_objectives(0.7), dragon_kills(0.4), vision_score(0.3) |
| MIDDLE | damage_to_champions(0.6), cs_per_min(0.3) |
| BOTTOM | damage_to_champions(0.7), cs_per_min(0.4) |
| UTILITY | vision_score(0.7), heal_on_teammates(0.3), shield_on_teammates(0.3), cc_time(0.3) |

공통 지표는 kda(0.8)·dpm(0.5)·gold_per_min(0.4)로 정리.

> 검증: 라인 골드차와 종합 MMR의 상관 0.78. 라인전 강자가 실제로 높게 평가됨 확인.

**변경점**: 퍼포먼스 점수 산출 로직을 포지션별로 분리. `PERF_BASE` / `PERF_LANE` / `PERF_ROLE` 구조 도입.

---

### v5 — 승부격차(blowout) 보정

모든 승리를 동일하게 s=1로 처리하던 것을, 압승/접전을 구분하도록 개선.

- 경기별 **blowout 강도** 계산: 팀 골드차(주 신호) + 게임시간(짧을수록 압승, 보조 신호)을 robust 표준화 후 결합, tanh로 −1~+1
- K값에 `× (1 + 0.25·blow)` 곱함 → 압승은 점수 크게, 접전은 작게 움직임

> 검증: 13분/골드차 1.3만 압승 → K×1.23, 49분/골드차 100 접전 → K×0.76

**변경점**: 1.5단계(승부격차) 추가, K 보정에 세 번째 항 추가.

---

### v6 — 온라인 증분 설계 (문서만, 미구현)

"게임 한 판 하면 즉시 MMR 변동"을 위한 설계를 별도 문서로 정리. **방법 A**(표준화 기준 동결 + 매 경기 즉시 변동) 채택. `build_baseline`(가끔) / `update_one_match`(매 경기) 2-진입점 구조.

**변경점**: 산식 불변. 운영 구조 설계 문서 추가.

---

### v7 — 시작 점수 1300

시작 점수를 1500 → **1300**으로 변경. 모두에게 동일한 기준선이라 순위는 불변, MMR 값만 전체 약 200점 하향 평행이동.

**변경점**: `INIT_MMR = 1300`.

---

### v8 — 신규 데이터 적용 (~6/19)

데이터를 6월 19일까지로 갱신. 2,443경기 → **2,689경기**, 기간 1/8~6/19. 동일 산식 재적용.

**변경점**: 입력 데이터 교체. 부계정 통합 후 203명, 정식 144 / 배치중 59.

---

### v9 — UI 정리 + 데이터 컷 강화

- **배치중 토글 제거**: 데이터가 없어 의미 없던 토글 삭제
- **10판 미만 완전 제외**: 데이터 자체에서 제거 (203명 → 161명). 10~19판은 배치중, 20판+ 정식 유지

**변경점**: 산식 불변. 데이터 노출 정책 강화 (제외 10판 / 배치중 10~19판 / 정식 20판+).

---

### v10 — UI 확장: 탭별 순위 + 지표 + 클랜 평균

- **탭별 순위**: 종합·TOP·JUG·MID·ADC·SUP 탭. 라인 탭은 해당 라인 MMR로 재정렬(5판+)
- **지표 표시**: 표·모달에 계산 지표값 노출
- **포지션별 지표 차등 표시**: 각 탭이 그 포지션 산식에 실제 쓰인 지표만 표시 (공통+특화). 누락됐던 특화 지표(탱킹·드래곤·힐·실드·CC) 계산 추가
- **클랜 평균 패널**: 상단에 평균 MMR·승률·지표. 탭 연동

**변경점**: 산식 불변. UI가 산식 구조를 정확히 반영하도록 개편.

---

### v11 — 라인별 베이지안 수축 (현재)

진단 결과: 라인 기록의 35%가 10판 미만 → 소표본 라인 MMR이 과대/과소평가. 종합엔 20판 컷이 있지만 라인엔 5판 컷뿐이던 문제.

**수축 공식** (라인 MMR에만 적용, 종합은 불변):

```
수축 MMR = (라인경기수 · 원래값 + 12 · prior) / (라인경기수 + 12)
```

- `prior` = 그 포지션의 경기수 가중 평균 MMR
- `SHRINK_K = 12`: 라인 12판이면 원래값:prior = 1:1, 많을수록 원래값 존중, 적을수록 평균으로 끌어당김

> 검증: 5~9판 라인 MMR std 18~25(평균 근처로 수렴), 50판+ 라인 std 218~256(실력대로 갈림). 소표본 극단값 완화.

**변경점**: 3단계(결과 집계)에 수축 적용. 포지션별 prior 계산 추가.

## 다음 후보 (미적용)

진단상 남은 개선 여지.

- **퍼포먼스 게인 튜닝**: MMR↔승률 상관 0.68. `PERF_GAIN`을 낮추면 승률 중심, 높이면 개인기량 중심
- **시간 가중(최근 폼)**: 5개월 누적을 동등 취급 중. 최근 경기 가중 시 "현재 실력" 반영. 단 "통산 실력"을 원하면 미적용이 맞음
- **수축 강도 조정**: `SHRINK_K`를 키우면(20) 소표본 더 강하게 평균화, 줄이면(6) 원래값 존중
